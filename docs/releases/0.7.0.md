# 808 Radio 0.7.0

**An FM + HD Radio receiver for Windows and macOS with RTL-SDR dongles, styled as a car stereo.**

![808 Radio](https://github.com/mattackerman808/808-Radio/raw/v0.7.0/docs/images/808radio.png)

## What it is

808 Radio turns a $30 RTL-SDR dongle into a proper radio: FM stereo with RDS, and **HD Radio** (NRSC-5) with album
art, multicast channels (HD1–HD8), weather and traffic maps, blended with the analog signal like a real HD receiver.
It finds the best gain for each station by itself and corrects the dongle's frequency error automatically.

The dongle can be on the computer or on a Raspberry Pi near the antenna running the standard `rtl_tcp` server, which
808 Radio finds on the network by itself.

## How it works

- **The receiver** is C#: the RTL-SDR's samples are filtered, demodulated to FM stereo with RDS, and the HD Radio
  sidebands go to [nrsc5](https://github.com/theori-io/nrsc5) for decoding. The analog and digital audio are blended
  the way a car receiver does it, so a weak HD station falls back to analog instead of dropping out.
- **The faceplate** is a car stereo: a dot-matrix display, HD program keys, presets, a tuning knob with detents.
  Press OPEN and it folds down to an instrument panel drawn at the display's refresh rate: spectrum and waterfall
  with click-to-tune, the FM multiplex, and live receiver statistics.
- **The weather map** is the station's own radar image (HD Radio's HERE image service) drawn over a street map of
  the same box from OpenStreetMap data, cached so it works without the internet.
- Windows builds use Windows Forms with Direct2D for the panel; macOS uses Avalonia. The receiver is the same code.

![The instrument panel behind the faceplate](https://github.com/mattackerman808/808-Radio/raw/v0.7.0/docs/images/808radio-open.png)

## What's new in 0.7.0

- **The weather map on Windows.** The radar over the street map is on both platforms now; the map code is shared.
- **The map works offline.** When a station's weather box becomes known, every map tile it could need is fetched
  and kept, so the radar has its street map with no internet connection. The map archive is checked for updates
  once a day; a failed fetch is retried every five minutes.
- **The station tells you what it sends.** The HD decoder reads the station's Service Information Guide, so the WX
  and TRAFFIC keys show at once whether a station sends maps: dark when it doesn't, lit when the first map is in,
  and the display's lights blink in between while the first image assembles.
- **HD-only seek.** The HD SEEK key (also in the right-click menu) makes seek skip analog-only stations: it waits a
  few seconds on each for HD sync and moves on. The [HD][SEEK] lights in the display show it at work.
- **A new faceplate layout.** Nine keys of one size in three rows left of the display, grouped by what they do:
  OPEN, DISP, COLOR on top; MUTE, WX, TRAFFIC in the middle; SRC, HD CH, HD SEEK at the bottom next to the seek keys.
  The tune knob sits above a volume knob of the same size in the corner. The signal meter is inside the display
  now, an antenna with five dots and an OVL light that comes on red if the dongle overloads.

![The weather radar over its street map](https://github.com/mattackerman808/808-Radio/raw/v0.7.0/docs/images/808radio-weather.png)

Since 0.6.0 (Mac fixes released as 0.6.1): window resizing works on the Mac, the small dot matrix is crisp on
non-Retina monitors, and the audio analyzer no longer shows through the open panel.

## Download

- **Windows 10/11 (x64)**: `808Radio-v0.7.0-win-x64.zip`. Unzip anywhere and run `808Radio.exe`. Self-contained:
  no installer, no .NET to install. The dongle needs the WinUSB driver once (Zadig); see the README.
- **macOS (Apple Silicon)**: `808Radio-v0.7.0-mac-arm64.zip`. Unzip and open `808 Radio.app`. Signed and notarized,
  with the native libraries inside; a USB dongle needs no driver on macOS.
